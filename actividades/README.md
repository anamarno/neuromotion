# Actividades del Proyecto Neuromotion

Esta carpeta contiene todas las actividades lúdicas e interactivas del Proyecto de Divulgación Científica Neuromotion.

## Estructura de Carpetas

### pasapalabra/
Juego de palabras cruzadas y acertijos relacionados con conceptos de neurociéncia y neuromotricidad.
- **pasapalabra1/**: Primera versión del juego
- **pasapalabra2/**: Segunda versión del juego
- Otros archivos y recursos relacionados

### respiracion/
Actividad interactiva sobre técnicas de respiración y control del sistema nervioso.
- Recursos educativos
- Ejercicios prácticos
- Material de enseñanza

Cada actividad tiene su propio README con instrucciones específicas.
